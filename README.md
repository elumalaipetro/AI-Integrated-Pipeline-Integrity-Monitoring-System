# AI-Integrated Pipeline Integrity Monitoring System

## Overview

This project is an AI-based Pipeline Integrity Monitoring System developed to assess pipeline health, predict corrosion risk, detect potential leaks, and estimate Remaining Useful Life (RUL). The system helps improve pipeline safety, reliability, and maintenance planning through risk-based analysis.

## Features

* Corrosion Risk Prediction
* Leak Detection System
* Health Score Assessment
* Probability of Failure (POF) Calculation
* Consequence of Failure (COF) Calculation
* Risk Index Evaluation
* Risk Matrix Generation
* Remaining Useful Life (RUL) Prediction
* Interactive Streamlit Dashboard
* High-Risk Pipeline Identification

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* Streamlit
* Machine Learning

## Dataset Parameters

* Pressure
* Temperature
* Flow Rate
* Pipe Age
* Wall Thickness
* Corrosion Rate
* Soil pH
* Soil Moisture
* Leak Indicator
* Health Score
* Risk Score
* POF
* COF
* Risk Index
* Risk Matrix
* RUL Years

## Dashboard Capabilities

* Real-time pipeline condition monitoring
* Risk score visualization
* Health score analysis
* Risk matrix distribution
* Top high-risk pipeline identification
* RUL monitoring

## Project Outcome

The system enables proactive maintenance planning by identifying high-risk pipeline segments, estimating failure probability, and supporting data-driven decision-making for pipeline integrity management.
